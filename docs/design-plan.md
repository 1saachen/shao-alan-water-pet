# v0.2 界面设计计划

依据已安装的 [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)。原生 PySide6 桌面界面，保留透明桌宠能力。

## 设计方向

喝水和桌宠是主角。使用清水、瓶身、涟漪的视觉语言；人物成为唯一的大幅视觉。降低信息密度，让喝水确认、下次提醒和大小调整能直接找到。

- 水蓝 `#1768D5`：主要按钮、选中导航、进度。
- 冰水 `#EDF7FF`：人物背景、状态提示。
- 深海蓝 `#203A59`：正文与标题。
- 纯白 `#FFFFFF`：页面、输入与气泡。
- 瓶盖绿 `#88B59C`：仅由角色水瓶带入，不作第二套强调色。
- 灰蓝 `#71839A`：说明、非关键时间信息。

字体：Microsoft YaHei UI 承担中文与正文；数字使用 Segoe UI。标题 30–38 px，段落 14 px，辅助说明 12 px。导航和控件统一用中文动作词。

## 版式

今日页：顶部导航；左边是喝水动作、当前记录、下一次提醒和最近记录，右边是人物与水纹构成的视觉。所有文字左对齐，人物独立居中。

```text
喝大水      今日 / 提醒与外观 / 台词        提醒状态
------------------------------------------------
先喝一口大水。                  人物
再做下一件事。                  水纹
我喝水了 / 找到桌宠              拿大水瓶
今日水量与进度
下次提醒时间 / 暂停
最近记录 / 撤销
```

设置页：提醒规则在左侧表单，人物预览、缩放滑条和比例预设在右侧；缩放立即生效并保存，文字保持可读。

台词页：左侧自定义台词编辑，右侧按场景试听，能直接让桌宠说当前台词。风格来源放在页脚解释区。

## 计划自查与修订

原方案里的编号侧栏、英文全大写小标签、相同圆角卡片已经过于接近通用控制台。新方案移除这些装饰，保留有含义的分隔线、输入边界和状态。水纹只服务人物场景，不铺满整个界面。字号与按钮焦点清晰，窗口按可用屏幕大小启动。

验收：桌宠缩放 50–200%，滚轮/右键/设置同步，重启保留；喝水、延后、暂停、免打扰及自定义台词仍然可用；三个页面均渲染查看，便携包独立启动。
